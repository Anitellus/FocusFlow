Focus Flow Complete Program Guide

1. Projects, Sub-projects & Hierarchy

Organize work into root projects and nested sub-projects. Sub-projects can be added to any project level as long as it has no active tasks. Tasks exist strictly at the lowest leaf project levels.

2. Task Management & Required Targets

Add tasks with an upfront Target Requirement (in minutes). Click a task row to make it active on the central focus clock. Use the delete button on any task row to remove tasks.

3. Focus Companions (Mascots)

Tier 1 companions are unlocked immediately. Higher tiers unlock at the Project Level based on cumulative project focus time (aggregated across sub-projects). Companions are displayed on the right edge of the main project in the sidebar.

4. Movement Modes & Physics Animations

Companions feature 4 movement behaviors: Still (frozen top-left), Roam (3x range straight lines, 90-deg wall rebounds), Float (aimless continuous curves), and Sleep (freezes at current location with Z-particles). Perform 2D Front Flips, Back Flips, Squish, or Hop animations.

5. Analytics, Streak & Heatmap

Switch to Analytics to view stats across Today, 7 Days, 30 Days, or All Time. The Focus Streak tile tracks consecutive days of activity, and the 30-Day Heatmap accurately displays work logged per calendar date.
